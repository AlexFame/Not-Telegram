# CODING — стиль кода и стандарты

Код должен быть чистым, понятным, современным, нативным, легко читаемым и расширяемым — без лишней сложности. Пиши код, который читается как окружающий: совпадай с его именованием и идиомами. Применение паттернов — по [PRINCIPLES.md](PRINCIPLES.md) (только когда упрощают).

---

## Swift

- Современный Swift: `async/await` вместо колбэков, structured concurrency, `Sendable` там, где данные пересекают акторы.
- **Value types по умолчанию** (`struct`, `enum`). `class` — только когда нужна ссылочная семантика или identity.
- Моделируй домен типами, а не строками и флагами: статус сделки — `enum`, а не `String`; недопустимое состояние должно быть непредставимо.
- Никаких `force unwrap` (`!`) и `try!` в продакшн-коде. `guard` для раннего выхода.
- Ошибки — через `throws` / `Result`, не через опционалы-как-ошибки.
- Осмысленные имена без сокращений. Ясность важнее краткости.

## SwiftUI

- Мелкие, композируемые `View`. Большой экран собирается из маленьких вью, а не пишется одним телом.
- Состояние принадлежит одному владельцу; вниз передаём данные, вверх — намерения. Однонаправленный поток (см. [ARCHITECTURE.md](ARCHITECTURE.md)).
- `@Observable` (Observation) для моделей представления вместо `ObservableObject`, где возможно. `@State` — для локального состояния вью.
- Никакой бизнес-логики во вью и никаких обращений к сети/хранилищу прямо из вью.
- Анимации явные и осмысленные (см. [DESIGN.md](DESIGN.md) — каждая анимация объясняет). Следим за производительностью: 60/120 fps, без лишних перерисовок.

## Общее

- **Не усложняй заранее.** Не вводи абстракцию, пока её не требует вторая реальная точка использования. Простое решение предпочтительнее «гибкого на будущее».
- Функции короткие, с одной ответственностью. Ранний возврат вместо вложенности.
- Комментируем «почему», а не «что». Плотность комментариев — как в окружающем коде.
- Каждый публичный тип домена покрыт тестами; логику держим в тестируемых чистых функциях.
- Избегаем техдолга: если решение временное — это явно помечено и локализовано за протоколом.
